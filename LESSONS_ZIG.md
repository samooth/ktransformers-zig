# Lessons Learned: Zig (Session Summary)

## Build System (build.zig)

### Zig 0.16 Specifics
- **Package format**: `.zon` files use enum literal syntax: `.name = .my_package` (not string)
- **fingerprint field**: Required in `build.zig.zon`, generated by `zig init`
- **`std.meta.stringToEnum(T, str)`**: Replaces old `std.meta.EnumVariant(T).tryTagFromName(str)`
- **Module imports**: Use `b.createModule()` with `.root_source_file` pointing to `src/root.zig`
- **Library creation**: `b.addLibrary(.{ .name = "...", .linkage = .dynamic, .root_module = mod })`
- **Install artifact**: `b.addInstallArtifact(lib, .{})` returns `*Step.InstallFile`, use `.step` for dependency

### C Interop
- **C macros**: Use `mod.addCMacro("NAME", "VALUE")` for defines
- **Include paths**: `mod.addIncludePath(.{ .cwd_relative = "path" })` works for C headers
- **Zig module paths**: `mod.addIncludePath()` does NOT work for Zig imports - use relative imports like `@import("runtime/memory.zig")`
- **C source files**: `mod.addCSourceFile(.{ .file = b.path("file.zig") })` - but Zig files cannot be added as C sources

### Common Errors & Fixes
- **"expected ',' after initializer"**: Switch expressions in Zig 0.16 need explicit `if/else` or array lookups, not inline switch
- **"unable to resolve comptime value"**: String concatenation for library names must be comptime-known
- **"found another zig file after root source file"**: All Zig files must be imported via `@import()`, not added as C sources
- **"Slice being concatenated must be comptime-known"**: Library names with runtime strings don't work
- **"expected function or variable declaration after pub"**: `pub struct` at top level of file needs `pub const X = struct { ... };`
- **"unused function parameter"**: Parameters with `_` prefix can still be flagged - add explicit `_ = param;`
- **"ambiguous use of '&&'"**: Use `and` instead of `&&` in Zig 0.16
- **"cannot compare strings with =="**: Use `std.mem.eql(u8, a, b)` instead
- **"expected type expression, found ';'"**: Extra `;` after function closing `}` - remove it
- **"expected ';' after declaration"**: Missing `;` after struct closing `}` - add it
- **"alignment is a reserved keyword"**: Use `alignment` or `align_offset` instead
- **"declarations not allowed between container fields"**: All struct fields must come before any methods
- **"else if not attached to if"**: Wrap single-line `if` body in braces: `if (cond) { ... } else if ...`

### Zig Syntax (0.16)
- `@intToFloat` doesn't exist - use `@as(f32, @intCast(val))` or similar
- `f32_MAX` doesn't exist - use `std.math.max(f32)` or similar
- `@round()` takes 1 argument, not 2 - use `@intCast(x + 0.5)` for rounding
- Unused parameters/locals are errors (use `_` prefix to silence)
- `std.mem.splitScalar(u8, str, ' ')` returns iterator, not slice - use `for` loop directly
- `std.StringArray` doesn't exist - use `std.ArrayList([]const u8)` or `[]`const u8`
- `pub type` not allowed at top level of file - use `pub const`
- `|var|` capture syntax changed - use `| var |` with spaces for OR, or rewrite as statements

### Module System
- Zig files import via `@import("relative/path.zig")` from the root module
- `addIncludePath()` adds C include paths, NOT Zig module paths
- Root module is set via `.root_source_file` in `createModule()`
- `src/root.zig` re-exports all submodules for proper module resolution

### Inline Assembly (AMX)
```zig
asm (
    "ldtilecfg [%0]"
    :
    : "r" (cfg)
    : "memory"
);
```
- Constraints: `"r"` for register, `"memory"` for clobber
- Tile registers referenced via `TileReg` enum

## Testing
- `b.addTest(.{ .root_module = test_mod })` creates test step
- Test modules need all imports added explicitly
- `@import()` paths relative to the test file location
- Use `test_mod.addImport("name", b.createModule(.{ .root_source_file = ... }))` to add named imports
- Don't use "root" as an import name - conflicts with builtin module
- `const` test variables can't be passed to `deinit(self: *T)` - use `var` for mutable structs

## Zig 0.16 API Changes (Discovered While Fixing)

### Standard Library Removals/Migrations
- **`std.atomic.Bool`** → **`std.atomic.Value(bool)`**: `std.atomic.Value(bool).init(false)`
- **`std.Thread.Pool`** → **Removed**: Use `std.Io.Group` or placeholder
- **`std.DoublyLinkedList(T)`** → **`std.DoublyLinkedList`**: Top-level type, use `std.DoublyLinkedList{}` (not `std.DoublyLinkedList(T).empty`)
- **`std.time.sleep()`** → **`io.sleep()`**: Now requires `Io` parameter. For simple cases, use spin-wait
- **`std.mem.eql` with `*c` slices**: String literals may be auto-cast to `[*c]const u8` which doesn't match `[]const u8`

### `std.mem.Allocator.alignedAlloc` Signature Change
```zig
// OLD (Zig 0.15):
allocator.alignedAlloc(alignment, n)

// NEW (Zig 0.16):
allocator.alignedAlloc(T, alignment, n)
// where alignment is comptime `?std.mem.Alignment` (enum of log2 values)
```

### `std.mem.Alignment` Enum
- Values are log2 of byte alignment: `Alignment.@"1"=0, @"2"=1, @"4"=2, ..., @"64"=6`
- To convert bytes: `@as(std.mem.Alignment, @enumFromInt(std.math.log2(alignment_val)))`

### Pointer Types Need Optional for Default `null`
- `[*]T = null` → `?[*]T = null` (in Zig 0.16, untyped nullable pointers require optional)
- `*anyopaque = null` → `?*anyopaque = null`

### Packed Structs Cannot Contain Arrays
- `packed struct { [N]u8 = undefined }` → ERROR
- Solution: Use `extern struct` or individual fields

### CPU Feature Detection
- `builtin.cpu.features.amx_int8` → May not exist on all targets
- Use `@hasField(std.Target.Cpu.Feature.Set, "amx_int8")` for comptime checks

### `std.Thread.getCpuCount()` Returns Error
- Old: `orelse 1`
- New: `catch 1`

### String Equality with Runtime Values
- `std.mem.eql(u8, f, "literal")` requires both args to be slices
- String literals work directly: `std.mem.eql(u8, f, "avx512vnni")` (not via intermediate const)
- `||` between two eql calls causes auto-cast issues - use `or` instead
